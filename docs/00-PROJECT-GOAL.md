# 00. Цель проекта

## Идея
Подписочный SaaS, который превращает одного турагента в «автоматизированное бюро»: платформа сама приводит клиентов
(блог + SEO), ведёт диалог (чат-бот), честно подбирает предложения, помогает довести продажу, формирует документы и
гайд для клиента на его языке. Агент платит подписку и подключает **свои** ключи (Anthropic, Stripe, API операторов) —
платформа не несёт расходов на токены и не обрабатывает деньги клиентов.

## Для кого
Малые турагентства и фрилансеры-агенты (ДАЧ-регион, русско-/немецко-/украиноязычная аудитория), которые продают чужие туры
с комиссией (Reisevermittler) и не хотят нести ответственность организатора.

## Выбранная форма деятельности
Агент — **посредник (Vermittler)**: ответственность за исполнение поездки — у оператора (Veranstalter). Платформа
технически закрепляет это: нет подтверждения брони ботом, оплата только по ссылке, созданной человеком, пакетные туры
только с подтверждённым Sicherungsschein, обязательные Impressum/реквизиты, прозрачные пометки ИИ. См. 04-LEGAL-DE.md.

## Путь агента
Лендинг → регистрация (проверка: подтверждение e-mail, юр.данные, USt-IdNr через VIES, ручное одобрение суперадмином) →
кабинет: бренд (лого, название, картинки, тексты, цвета), бот (тон, правила, языки), интеграции (BYOK), офферы,
блог (частота, тон, теги, RSS-темы, Telegram), заявки/CRM, отзывы, статистика, домен.

## Путь клиента агента
Статья в поиске → сайт агентства → чат-бот выясняет цель/бюджет/даты → показывает подходящие реальные офферы без
выдумок → заявка (с согласием на обработку данных) → агент ведёт сделку → оплата (опционально Stripe агента) →
PDF-документы и гайд на языке клиента → отзыв (только от реальных клиентов, модерация).

## Метрики успеха MVP
- Агент от регистрации до опубликованного сайта < 30 минут.
- Бот отвечает без выдуманных цен/наличия (ручная выборка 50 диалогов).
- Ноль утечек между тенантами (тесты + аудит), ключи не попадают в логи.
- Стоимость инфраструктуры на 1 агента < ~5 €/мес без LLM (LLM оплачивает агент).

## Бизнес-модель
Подписка (тарифы по числу сайтов/постов/диалогов), свой домен — платная опция. Тарифы и биллинг самой платформы —
в роадмапе (этап 3), пока подписка вручную через суперадмина.
