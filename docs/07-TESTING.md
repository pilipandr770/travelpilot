# 07. Тестирование

## Автотесты
`python -m pytest -q tests` (SQLite) или с `TEST_DATABASE_URL=postgresql://…` — 64 теста. LLM и Stripe замоканы; сеть не нужна.
Покрыто: регистрация/логин/lockout, сброс пароля, изоляция тенантов, шифрование и скрытие ключей, правила публикации, чат (лимиты, Origin, согласие на лид),
блог (санитайзер, draft, воркер), Stripe webhook и restricted-ключи, PDF, SSRF, загрузки, XSS/SQLi, CSRF, админ-flow, theme.css.

## Ручной сценарий (10 минут)
1. Зарегистрироваться → ссылка из `make logs` → войти.
2. «Юр. данные» (все поля) → «Бренд» (лого, цвета) → «Запросить проверку».
3. `/admin/` под суперадмином → одобрить → в кабинете «Опубликовать».
4. Открыть `http://<slug>.localhost:8000`; «Интеграции» → вставить свой Anthropic-ключ → «Проверить».
5. «Офферы» → добавить 2–3 → в чате сайта спросить про поездку; проверить, что бот предлагает только их и просит согласие перед сохранением заявки.
6. «Блог» → сгенерировать пост → черновик → редактировать → опубликовать → `/blog`, `/sitemap.xml`, `/blog/feed.xml`.
7. Лид → бронь → PDF-документы (de/ru/uk/en).
8. Stripe test-ключ (restricted) + `stripe listen --forward-to` для webhook (секрет whsec — в интеграциях).
9. «Домен»: добавить свой тестовый домен, проверить TXT/CNAME.
