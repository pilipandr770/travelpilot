# 04. Правовая рамка (Германия/ЕС) — ориентир, не юридическая консультация

Все тексты в проекте — **шаблоны**; перед запуском необходима проверка юристом (Reiserecht, IT-Recht).

## Vermittler vs Veranstalter
- **Reisevermittler** продаёт чужие туры (договор заключается между клиентом и организатором). Ответственность за поездку у Veranstalter.
- Организатор (§651a ff. BGB) — собственные пакетные туры или «сборка» пакета: пакетные права, ответственность, **Sicherungsschein (§651r BGB)**.
- Риск «случайного» превращения в организатора: агент сам комбинирует услуги в пакет. Платформа блокирует оплату пакетов без `sicherungsschein_confirmed` и просит агента подтвердить роль.
- Информационные обязанности (Art. 250 EGBGB, Formblatt) — исполняет организатор; агент передаёт их клиенту.

## Платформа и агенты
- Impressum (DDG §5) — у платформы и у каждого агентства (поля в «Юр. данные», сайт не публикуется без них).
- DSGVO: агент — Verantwortlicher, платформа — Auftragsverarbeiter → AVV (шаблон в /legal/avv). Согласие в форме лида/чата, `purge-chats` для хранения по сроку, экспорт/удаление данных по запросу.
- Передача данных в Anthropic/Stripe — по ключам агента: указать в Datenschutz агента (шаблон есть).
- EU AI Act (прозрачность): бот помечен как ИИ; блог-статьи с пометкой «KI-generiert».
- UWG: никаких фальшивых отзывов, «лучшая цена» без основания; отзывы — только модерация реальных.
- USt-IdNr проверяется через VIES (информативно).
- Платежи: деньги идут напрямую на Stripe агента, платформа не держит средства → не платёжный посредник.
- Gewerbeanmeldung/Erlaubnis агента — ответственность агента; платформа просит подтверждение при регистрации.
