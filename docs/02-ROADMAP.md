# 02. Пошаговая реализация и план развития

Статус: ✅ сделано в этом репозитории · ⬜ предстоит.

## Этап 0 — Запуск локально (1 день)
1. ✅ `cp .env.example .env`, `gen-keys`, `docker compose up --build`.
2. ✅ Создать суперадмина, пройти сценарий из docs/07-TESTING.md.
3. ⬜ Заполнить `PLATFORM_OPERATOR_*` (Impressum) и реальные тексты лендинга.

## Этап 1 — MVP-ядро ✅
Регистрация/модерация, мультитенантный сайт, бренд, бот (BYOK Anthropic), офферы вручную/CSV, лиды, брони, PDF-документы,
автоблог + Telegram, отзывы, статистика, свой домен, суперадмин.

## Этап 2 — Подготовка к проду (1–2 недели)
1. ⬜ **Безопасность** (docs/03-SECURITY.md): 2FA TOTP + recovery-коды, прогон чек-листа инъекций, зависимости (pip-audit), бэкапы.
2. ⬜ Прод-деплой: VPS, DNS wildcard, `make prod`, SMTP (Postmark/Mailgun/SES), мониторинг (Sentry, uptime).
3. ⬜ Юрист: AGB, Datenschutz, AVV, шаблоны для агентов (docs/04-LEGAL-DE.md).
4. ⬜ Живые тесты: Duffel test-key, Hotelbeds sandbox, Stripe test mode + CLI webhooks.
5. ⬜ Перевод кабинета на немецкий полностью; украинский для кабинета.

## Этап 3 — Монетизация
1. ⬜ Биллинг платформы (Stripe Billing: тарифы, триал, dunning), лимиты тарифов (посты/диалоги/сайты).
2. ⬜ Платный кастомный домен, white-label.
3. ⬜ Онбординг-мастер (чек-лист в кабинете уже есть), демо-агентство.

## Этап 4 — Рост продукта
1. ⬜ Кросспост X и WhatsApp (Business API) · Instagram/Facebook по запросу.
2. ⬜ Больше коннекторов: Hotelbds, Amadeus self-service, Kiwi/Tequila, TUI/DERTOUR-фиды, GetYourGuide; единый формат Offer.
3. ⬜ SEO-расширения: схема JSON-LD (TravelAction, FAQ), internal linking, Search Console API, автообновление старых статей.
4. ⬜ Email-цепочки клиентам (до/после поездки), напоминания о документах, визовые чек-листы (Auswärtiges Amt уже подключён).
5. ⬜ Мобильный PWA-кабинет, push-уведомления о новых лидах.
6. ⬜ Мультиязычные статьи (авто-перевод + hreflang).

## Этап 5 — Масштаб
Очередь задач (Celery/RQ) вместо тик-воркера · S3-хранилище медиа · отдельные read-реплики · SSO для агентств с командами
(роли: owner/editor/agent) · публичный API и вебхуки · аудит-экспорт.
